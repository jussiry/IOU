  1. Copy encrypted key and move it to a new device or domain.
  2. If transferring to a new domain, it needs to be included in current users relay servers.
  3. Open Tally app on new device or domain.
  4. Enter passphrase and paste the encoded key on the Welcome page.
  5. Keep both apps open until user data has been transferred to new device.
  6. You can now keep using two devices or delete user from old device.
