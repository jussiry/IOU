## Available trust

Calculated by summing the trust limit of each friend, to which the current loan balance is added. E.g. Trust limit between Alice and Bob is 50€ and currently Alice owns Bob 30€ -> Alice has 20€ available trust and Bob has 80€ available trust. Available trust cannot be negative, so if Alice owns Bob 100€, then Alice has 0€ available trust and Bob has 150€.
